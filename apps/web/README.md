# Web

Cliente React + Vite/TypeScript. El shell M0 compila y se sirve localmente; las rutas y funciones M1–M4 siguen pendientes. Consume únicamente la API pública bajo `/api/v1` y no puede importar la capa de DB.

- Responsable: P2.
- Etapas: base M0; funcionalidades M1–M4 según cada módulo.
- Desarrollo: `pnpm --filter @devpath/web dev`.
- Build: `pnpm --filter @devpath/web build`.
- Estado: base técnica M0 implementada; sin funciones de negocio.
